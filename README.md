<h1>Snake Game</h1>
<p>Retro snake game</p>

<h2 id="about">About</h2>
<p>This project is a simple implementation of the classic Snake game. The player controls a snake that moves around the game board, eating food to grow longer. The game ends if the snake collides with the walls or itself.</p>

<h2 id="installation">Installation</h2>
<p>To run this project locally, follow these steps:</p>
<ol>
    <li>Clone the repository: <code>git clone https://github.com/your-username/snake-game.git</code></li>
    <li>Navigate to the project directory: <code>cd snake-game</code></li>
    <li>Open <code>index.html</code> in your web browser.</li>
</ol>

<h2 id="usage">Usage</h2>
<p>To play the game, press the spacebar to start. Use the arrow keys to control the direction of the snake. The game will keep track of your score and high score.</p>

<h2 id="features">Features</h2>
<ul>
    <li>Classic Snake gameplay</li>
    <li>Score and high score tracking</li>
    <li>Increasing difficulty as the snake grows</li>
</ul>
